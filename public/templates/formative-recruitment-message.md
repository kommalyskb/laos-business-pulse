# UX-03 Formative Test · Recruitment Message

ສະບາຍດີ,

ພວກເຮົາກຳລັງທົດສອບຕົວຢ່າງແພລັດຟອມສຳລັບຊອກຫາຮ້ານອາຫານ ແລະຮ້ານກາເຟຈາກວິດີໂອຣີວິວ. ພວກເຮົາຢາກເຊີນທ່ານມາລອງໃຊ້ປະມານ 30–40 ນາທີ.

ການທົດສອບນີ້ແມ່ນທົດສອບແພລັດຟອມ ບໍ່ແມ່ນທົດສອບຄວາມສາມາດຂອງທ່ານ. ບໍ່ຈຳເປັນຕ້ອງກຽມຕົວ ແລະສາມາດຢຸດໄດ້ທຸກເວລາ. ຂໍ້ມູນຜົນທົດສອບຈະໃຊ້ Participant ID ແທນຊື່.

ຖ້າທ່ານສົນໃຈ ກະລຸນາຕອບກັບວ່າ:

1. ປົກກະຕິທ່ານຊອກຮ້ານຜ່ານ Social Media, Search/Map ຫຼືວິທີອື່ນ?
2. ທ່ານສະດວກວັນ ແລະເວລາໃດ?
3. ທ່ານຈະໃຊ້ smartphone ຂອງຕົນເອງ ຫຼືຕ້ອງການອຸປະກອນຈາກທີມ?

ໝາຍເຫດສຳລັບຜູ້ຮັບສະໝັກ: ຢ່າສົ່ງ Prototype tasks ລ່ວງໜ້າ ແລະຢ່າບອກວ່າ UI ຄວນໃຊ້ແນວໃດ.
